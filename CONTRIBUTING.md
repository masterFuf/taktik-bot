# Contributing

Thank you for your interest in TAKTIK.

## Issues are welcome

Open an issue on [GitHub](https://github.com/masterFuf/taktik-bot/issues) for:

- a bug: the command you ran, what you expected, what happened, and the log;
- a version of Instagram or TikTok that breaks a workflow: the app version (`adb shell dumpsys
  package com.instagram.android | grep versionName`), the language of the app and the workflow id;
- a question about the engine or the command line.

Please remove from what you paste anything personal: account names, message contents, phone serial
numbers, API keys.

## Pull requests are not accepted for now

The project is going through a clean-up of its code base, and pull requests from outside the
project are not merged in the meantime, whatever their quality. A pull request will be closed with
a pointer to this file; if it fixes a bug, please open an issue describing the bug instead.

There is no contributor licence agreement to sign.

This may change once the clean-up is over; this file will say so.
