# Install only when you need to intercept and save Instagram/TikTok images via mitmproxy.
#
# Usage:
#   pip install -r requirements-media.txt
#

# Only install if you know what you are doing and on devices you own or control.
#
# Exact versions: scripts/audits/audit_type_errors.py measures its baseline with requirements.lock
# plus these packages (pyright reads their types), so another version could move the counts.
